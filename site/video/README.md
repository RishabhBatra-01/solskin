# Rub footage

Drop the real clip in here as `rub.mp4`, then add `data-src="video/rub.mp4"` to the
`<video id="cinemaVideo">` element in `../index.html`.

With no `data-src`, the 3D shader rub plays instead and the page is complete either way —
nothing breaks if this folder stays empty.

`scrub-test-clip.mp4` is a synthetic gradient I generated to prove the scrub pipeline works.
It is **not** brand footage. Delete it once the real clip is in.
